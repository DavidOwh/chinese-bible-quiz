一起认识圣经 - 使用说明

1. 双击 index.html 即可在浏览器打开。
2. 这是离线版原型，不需要安装，也不需要网络。
3. 学习进度、错题和最高分保存在当前浏览器。
4. 若要让全教会用链接打开，可把整个文件夹上传到：
   - Netlify Drop
   - GitHub Pages
   - Cloudflare Pages
5. 上传后可把网址制成 QR Code，放在教会投影片、WhatsApp 或 Telegram。

主要功能：
- 四个难度，共40题
- 每题四个答案
- 即时解释与经文出处
- 每日一题
- 错题复习
- 学习进度
- 长者大字模式
- 中文朗读题目
- 手机、平板、电脑均可使用
